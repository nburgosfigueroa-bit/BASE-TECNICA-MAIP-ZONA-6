# Base Técnica Maipú Zona 6

Tablero informativo de hitos operativos para trabajadores de la Zona 6.

## 1. Contenido

- Hitos de seguridad y respuesta ante emergencias.
- Resumen de aseo, riego, corte, poda e infraestructura.
- Programación operativa de referencia de junio de 2026.

## 2. Fuentes

- Bases Técnicas Generales de Licitación de 2024.
- Extracto seguro de `GANTT BT - JUNIO 2026.xlsx`, sin datos personales.

## 3. Publicación

El archivo `artifact.json` es el archivo maestro del tablero. `index.html` es la versión autónoma publicada en GitHub Pages.

Sitio: <https://nburgosfigueroa-bit.github.io/BASE-TECNICA-MAIP-ZONA-6/>
